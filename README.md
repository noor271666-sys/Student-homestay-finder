# Student Homestay Finder

A website that connects students of Bahria University, Islamabad with local host families who have a spare room to rent. Built for the CSC-114 Introduction to ICT course project, Fall 2026.

## Purpose

Students who move to Islamabad from other cities usually search for a room through scattered Facebook and WhatsApp posts that often leave out the rent, distance, facilities or house rules. This website puts everything in one standard format. Families can list a room, and students can search, filter and compare rooms that fit their budget and needs.

## Pages

1. Home
2. Browse Rooms (with filters)
3. Room Details
4. List Your Room (host form)
5. Find a Room (student requirements form)
6. About and FAQ

## Features

- Filters for rent, distance, gender-specific housing, meals and Wi-Fi
- Shortlist and compare rooms
- Validated forms for students and hosts
- FAQ with questions that open and close
- Responsive layout for phone, tablet and desktop

## Technologies

HTML5, CSS3, JavaScript, Git and GitHub

## How to run

1. Download or clone this repository.
2. Open `index.html` in a web browser (Chrome, Edge, Firefox or Safari).

No installation or server is needed. The site is front-end only, with no database. The rooms shown are sample listings written by the team, and form data is not stored or sent anywhere.
